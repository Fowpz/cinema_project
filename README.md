# Система кинотеатров

Учебный проект: мобильное приложение для кинотеатров

## Структура рабочей области

CinemaApp/       Клиент на Expo и React Native
cinema-backend/  API на Express

## Авторизация API

Backend подписывает JWT алгоритмом HS256 и проверяет подпись, срок действия и пользователя из базы данных на защищённых маршрутах. Токен содержит только идентификатор пользователя; роль и данные пользователя читаются из базы, а не принимаются из клиента.

Перед запуском backend задайте в `cinema-backend/.env` случайный `JWT_SECRET` длиной не менее 32 байт. Сгенерировать значение можно командой:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Не публикуйте секрет и не используйте значение-заполнитель из `.env.example`.
